授業のたびの出欠を、タップだけで。
学期末の転記は、そのまま貼り付け。

中学・高校の先生のための出欠記録アプリです。インストール不要、ブラウザで開くだけ。いまは無料でお使いいただけます。

アプリを開く（無料） 学校のICT担当の方へ

Googleアカウントでログインして使います。学校のアカウントでも、個人のアカウントでもかまいません。

こんな手間を減らすための道具です

  • 紙の教務手帳から、校務支援システムへ転記する。学期末に、クラスごと・科目ごとに授業時数と欠席時数を数え直していませんか。
  • 出席率を電卓で出す。気にかけたい生徒を見つけるのに、毎回計算が要ります。
  • 記録し忘れに気づけない。抜けたコマがあると、授業時数が合わなくなります。

このアプリは校務支援システムの代わりではありません。その前段の「教務手帳の代わり」として、毎時間の記録と、学期末の集計だけを引き受けます。

使い方は3つの手順だけ

1名簿を貼り付ける
クラス／出席番号／名前／ふりがな／役員 の5列を、スプレッドシートからコピーして貼るだけ。
2時間割を登録する
曜日×時限のマスに、担当するクラスと科目を入れます。
3授業でタップする
その日の授業一覧から選び、欠席の生徒をタップ。全員出席の日はボタン1つ。

座席表からでも、名簿からでも

1 佐藤2 鈴木3 髙橋 4 田中5 伊藤6 渡辺
黒 板

座席表は任意です。作らなくても名簿から記録できます。座席の並びは学級のものをそのまま作れて、座席替えは席をタップして入れ替えるだけです。

欠席の理由は、あとから足せます。授業中に理由まで聞かれると手が止まるので、まずタップだけ。落ち着いてから「＋ 理由」で入れられます。

学期末にできること

校務支援システムへの転記用に出力
クラス／出席番号／授業時数／欠席時数の形で、科目ごとに出します。スプレッドシートに出力するか、コピーしてそのまま貼り付けられます。転記先で科目が分かれている場合は、割合を登録しておけば自動で分かれて出ます。
記録し忘れた授業のお知らせ
時間割にあるのに記録が残っていない授業を一覧にします。出力の前にも警告します（記録が抜けていると授業時数が合わないためです）。
出席率のレポート
クラス別・科目別・生徒別の出席率。出席率が低い生徒の人数がタブにバッジで出るので、開かなくても気づけます。
座席表・時間割の印刷用PDF
Googleドライブに保存できます。アプリを開けない校務用のパソコンにも、ドライブ経由で渡せます。
他の先生と共有
授業（クラス＋科目）ごとに、見てもらうか一緒に出欠をつけるかを選んで共有できます。同じクラスの他の科目も、他のクラスも相手には渡りません。
学校と自宅で同じ記録
同じGoogleアカウントでログインした端末どうしで自動的に同期します。教室のタブレットで記録して、職員室のパソコンで出力できます。

記録はどこに保存されますか

先生ご自身のGoogleドライブと、お使いの端末の中だけです。開発者は生徒のデータを一切預かりません。当方にサーバーもデータベースもありません。

  • Googleアカウントに求める権限は、このアプリが作ったファイルだけを読み書きできる権限（drive.file）と、画面表示用のメールアドレスだけです。ドライブの他のファイルは読み取れません。
  • 通信は「先生のブラウザ ↔ Google」の間だけで完結します。当方のサーバーを経由しません。
  • 広告はありません。生徒の情報を外部に送ることもありません。
ご利用の前に、学校または教育委員会の承諾をご確認ください。生徒の氏名や欠席理由を教員個人のクラウド領域に保存することを制限している場合があります。学校から配布されたGoogleアカウントでのご利用をおすすめします。

よくあるご質問

インストールは必要ですか？
不要です。ブラウザで開くだけで使えます。スマホやタブレットでは「ホーム画面に追加」すると、アプリのように起動できます。
遅刻・早退は記録できますか？
できません。出席と欠席の2つだけです。現場の先生に伺って、授業ごとの記録には2つで足りると判断しました。欠席の理由（保健室／その他＋メモ）は残せます。
使い始める前の記録も入れられますか？
入れられます。日付・時限・科目を見出しにした表を貼り付けると、過去の出欠をまとめて取り込めます。
年度が変わったらどうなりますか？
集計は年度（4月〜翌3月）と任意の期間を選べます。名簿は新しいクラスとして入れ直せます。
ブラウザのデータを消したら記録は消えますか？
Googleドライブへの同期を使っていれば残ります。ログインしてお使いください。ログインを必須にしているのは、この事故を防ぐためです。
学校のパソコンで開けません。
校内のフィルタリングで止まっている可能性があります。下の「学校のICT担当の方へ」をご覧ください。資料が必要でしたら、お送りします。

学校のICT担当の方へ

本アプリは HTML と JavaScript だけの静的なページです。ファイルのダウンロード実行やプラグインの導入は不要で、生徒の情報が提供者側に送られることはありません。

フィルタリングやSSLインスペクションの設定でご確認が必要な場合は、次のドメインをご参照ください。

shukketsu.ynsysapp.comアプリ本体の表示必須
accounts.google.comGoogleアカウントでのログイン任意

SSLインスペクションの除外をご検討ください。本アプリの通信には生徒の氏名・欠席理由が含まれます。除外していただくと、学校側の機器がその内容を復号せずに済みます。
Googleへの通信を許可できない場合も、アプリ単体で出欠の記録はできます（記録は端末内のみに保存されます）。
